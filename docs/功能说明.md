# 墨匠 · 功能说明

> 版本 0.1.0 ｜ 本地运行的写作与笔记工作台
> 数据全部存在本机 `文档/墨匠`，Markdown + JSON，不锁在应用里。

---

## 1. 定位

墨匠不是「AI 帮你写小说」的工具，是**作者主导的写作台**。

三条设计原则贯穿所有功能：

1. **本地优先**：体检、基线、账本、伏笔、黄金三章全部用规则在本机算，0 token、0 网络请求
2. **可验证**：每一条结论都要能追溯到具体证据（命中哪句、差多少分、哪个字段冲突），不说"感觉不够好"
3. **不假装**：抓不到就说抓不到，缺数据就标"待补"，绝不用编造的内容填充

只有主动调用模型时，正文才会发给你选的服务商。

## 2. 三种项目类型

新建时选一次，之后界面按类型显示不同工具。

| | 写小说 | 写文档 | 记笔记 |
|---|---|---|---|
| 内容目录 | `正文/` + `细纲/` | `文档/` | `文档/` |
| 命名方式 | 001、002 编号 | 按标题命名 | 按标题命名 |
| 左栏 | 正文/细纲两个 tab + 章节列表 | 目录树 | 目录树 |
| 写作工具 | 全套（见第 5 章） | 只有画板 | 只有画板 |
| 编辑器 | 行号 + 命中高亮 + 体检分数 | 无行号、干净 | 无行号、干净 |
| 右栏 | 体检 + AI 对话 | 只有 AI 对话 | 只有 AI 对话 |

老数据没有 `kind` 字段时一律按小说处理，不需要迁移。

## 3. 首页

启动后先到首页，选「做什么」再进对应界面。

**三个入口卡片**

- 写小说：章节体系 + 体检 + 八问大纲 + 账本伏笔
- 写文档：目录结构 + 干净编辑器
- 记笔记：随手记、标签、全局搜索

点卡片 → 填名称（小说可选题材）→ 创建 → 直接进工作台。

**已有项目**

下方网格列出全部项目，显示名称、类型徽章、篇数、字数、最后编辑时间。支持：

- 搜索（按名称）
- 悬停显示删除按钮（进回收站，可恢复）
- 点卡片直接打开

## 4. 编辑器

所有项目共用一套 Markdown 编辑器。

**基本操作**

| 操作 | 说明 |
|---|---|
| 保存 | `Ctrl+S`，或等待自动保存（切换文档时也会存） |
| 加粗 | 选中文字后点 `B`，或在工具栏点 |
| 斜体 | 点 `I` |
| 小标题 | 点 `H`，在本行开头加 `## ` |
| 引用 | 点 `❝`，加 `> ` |
| 列表 | 点 `≡`，加 `- ` |
| 分隔线 | 点 `—` |
| 专注模式 | 隐藏左右栏，只留正文 |

**标签**

编辑器上方有一行标签栏，`+ 标签` 添加，点 `×` 删除。标签存在文件开头的 frontmatter 里：

```markdown
---
tags: 工作, 会议
---

# 周会记录
```

一行 `---` 包起来的部分在编辑器里是隐藏的，不会干扰写作。左栏可按标签筛选。

**MD 对照**

工具栏点「MD 对照」，中栏一分为二：左边源码可编辑，右边实时渲染排版（章标题居中、段落首行缩进两字）。

渲染只覆盖常用语法（标题、粗体、斜体、代码、引用、列表、分隔线、链接）。HTML 标签会被转义，文档里写 `<script>` 只会显示成文本。

## 5. 小说专属工具

### 5.1 章节与细纲

左栏两个 tab 切换：

- **正文**：实际稿子，编号 001、002……
- **细纲**：本章要写什么，3–5 条情节节拍

两者分开存，体检只跑正文。

### 5.2 词库体检

右栏「体检」页签，改字 1.2 秒后自动重算，也可手动点「重新体检」。

12 类检测，每类都能定位到具体句子：

| 类别 | 查什么 |
|---|---|
| 措辞腔调 | "顿时""不由得""不由自主"这类书面腔 |
| 心理套话 | "心中一动""心中一凛""心中暗想" |
| 环境滥喻 | "仿佛在诉说什么"式的景物拟人 |
| 连接词 | "然而""于是""紧接着"密度过高 |
| 总结升华 | 章末"这一刻他终于明白"式的强行拔高 |
| 句式模板 | 连续相同句式（三个"他…"开头） |
| 情绪直述 | 直接写"他很愤怒"而不是用动作表现 |
| 节奏 | 连续短句成串（"转身。抬头。低头。"） |
| 重复 | 同一短语在邻近段落反复 |
| 对话 | 引号内超过 80 字不换气 |
| 口语化 | 正文里混入网络用语 |
| 标点情绪 | 感叹号、问号连用 |

**评分**：按千字密度扣分，千字折算下限为 1（短文本不会被放大十倍）。

**命中高亮**：被命中的行在编辑器里直接加底色，左侧还有一条琥珀色竖线，不用在右栏和正文之间来回找。

### 5.3 六维基线与文风漂移

六个可复算的指标：

| 维度 | 算法 |
|---|---|
| 句法复杂度 | 总字数 / 句数（字/句） |
| 修饰密度 | 每千字「的/地/得」出现次数 |
| 抽象度 | 每千字抽象名词命中数 |
| 动作密度 | 每千字动作动词命中数 |
| 不确定性 | 每千字「似乎/仿佛/大概」命中数 |
| 留白指数 | 每千字省略号、破折号、问号数 |

「建基线」用你认可的 3–10 章正文算 μ±σ，之后每章和基线对比，偏离超过 2σ 的维度会标出来。

**用途**：换模型续写时，判断文风有没有漂。因为全是计数，同一段文字任何人算都是同一个数，不存在"AI 觉得像不像"。

### 5.4 账本

记录人物、物品、地点的当前状态，防止前后矛盾。

- **状态树**：主体 → 字段 → 值，如 `林昭.realm = 开八门第一门`
- **变更历史**：每次改动记一条 RFC6902 patch，带章号
- **从正文落账**：正文里写 `[[账本|林昭|realm|开八门第二门]]`，点「提取」生成待落账列表，逐条或全部应用
- **冲突提示**：正文标的和账本记的不一致时，顶部红条报出来，精确到字段

不做自动写入——正文也可能写错，最终由作者确认。

### 5.5 伏笔

登记 → 提及 → 回收。

- 每条记：内容、埋设章、计划回收章
- 超过 20 章没动静的标黄；过了计划回收章还没收的标红
- 已回收的划线沉底

### 5.6 人设卡

每个角色一张卡：身份、性格、缺陷、说话方式、情绪基线、语用演变。

**说话方式**含句长档位（短/中/长）、口头禅、语言禁区、对主角的称呼。

**两项检测**：

- **OOC**：从当前章正文里按"名字前后 40 字的引号内容"启发式提取台词，检查禁区词、句长偏离、称呼缺失
- **千人一腔**：选另一个角色对比，用词 Jaccard 相似度 60% + 句长相似度 40%，≥ 0.75 报警

界面上明确标注"台词是启发式提取的，可能串"，结果只作参考。

### 5.7 八问大纲

**只有小说项目有。**

八个问题逐个问，一次一问：

题材 → 金手指 → 主角 → 核心冲突 → 基调 → 篇幅 → 差异化 → 章末钩子

- 没答完禁止生成大纲（闸门）
- 每题可跳过，跳过会记默认值并标黄
- 答完点「生成」输出 `大纲.md`，可反复重新生成

### 5.8 开写包

写新章前，把需要的信息一次性摆出来。共 16 项：

| 项 | 来源 |
|---|---|
| 上一章承接口 | 上一章末尾 300 字 |
| 上一章结尾钩子 | 上一章最后一段 |
| 本章细纲 | `细纲/00N.md` |
| 出场人物卡 | `人设/*.md` |
| 待回收伏笔 | `伏笔.json` |
| 禁用词 | 设置 |
| 六维基线 | `基线.json` |
| 锚段 | 书根目录 `锚段.md` |
| 上次体检结论 | 上一章现场重算 |
| 账本摘要 | `账本.json` |
| 开写清单 | 设置 |
| 读者期待 | 细纲 |
| 时间线 | 账本里的时间字段 |
| 本章硬约束 | 字数目标 + 叙事人称 |
| 连续性提醒 | 账本里的地点、伤势等 |
| 风格样本段 | 基线第一章开头 400 字 |

取不到的项显示「待补」和补救动作，不编内容。

两个出口：

- **复制提示词**：整包渲染成文本，粘到任何地方
- **发给 AI**：塞进右栏 AI 输入框并自动切到对话页，补一句"接着写 1200 字"就能发

### 5.9 黄金三章

自动读前 3 章，每章六项打分：

| 项 | 判断依据 |
|---|---|
| 钩子强度 | 开头 200 字里有没有疑问/冲突/反常/具体信息 |
| 开场节奏 | 前三段平均句长离 18 字多远 |
| 冲突密度 | 每千字冲突词命中数，理想 3–10 |
| 设定克制 | 专有名词密度，> 25/千字开始扣分 |
| 字数达标 | 是否到目标的 90% |
| 对话占比 | 引号内字数 / 总字数 |

分数下面直接给"开头 200 字里没有明确的疑问、冲突或反常"这类人话结论。

### 5.10 市场调研

**自动抓取**（尽力而为，服务器上的页面结构随时可能变）

起点 / 晋江 / 七猫 / 飞卢 / 番茄，各取榜单前 20。按页面实际编码解码（飞卢是 GBK），过滤混进来的章节标题。

**手动录入**（日常主力）

从浏览器复制榜单直接粘贴，认三种格式：

```
1 夜的命名术 会说话的肘子
2、大奉打更人 | 卖报小郎君
第3名	诡秘之主	爱潜水的乌贼
```

**报告**：写入 `报告/市场.md`，含各平台状态、条目、事实观察（书名平均长度、高频词、数据缺口）。只陈述事实，不给选题建议。

抓不到的平台标 degraded，不编数据。

### 5.11 剧情编排

小说项目的专属画板，用节点图理剧情。

- 双击空白新建节点，拖拽移动，从卡片右侧圆点拉到另一张卡片左侧连线
- 五种节点：铺垫 / 转折 / 高潮 / 伏笔 / 悬念
- 三种连线：因果推进（虚线流动）/ 平行推进 / 伏笔关联
- 节点可绑定章节，可标注出场人物

**AI 结构诊断**

点「AI 诊断」，整张图序列化后发给当前模型：

```
[n1] 铺垫 | 柴房醒来 | 林昭在天没亮时醒来… | 人物：林昭 | 第1章
n1 → n2（因果推进）
```

模型必须只回 JSON，结论要带 `nodeIds`。编造的节点 id 直接丢弃，说空话的结论被过滤；解析失败原样展示并标"格式不合规"，不假装成功。

能查六类问题：节奏（连续同类节点）、断链（埋了没回收）、因果薄弱、人物缺席、高潮位置失衡、支线过载。

结果每条带可点击的节点 id，点了相机飞过去；有问题的节点边框呼吸。

## 6. 通用能力

所有项目类型都有。

### 6.1 目录树

- 支持多级文件夹，可折叠
- 文件夹显示子项数量
- 父文件夹上新建文档会落在该文件夹里

### 6.2 全局搜索

`Ctrl+Shift+F` 或顶栏「搜索」。

- 跨所有项目搜正文内容，中文按字面匹配
- 结果显示：书名 / 文档名 / 行号 / 命中片段
- 点结果直接跳到那篇并切到对应位置

只扫内容目录，跳过报告和版本快照。

### 6.3 快速记录

`Ctrl+Shift+N` 或顶栏「+ 记一条」。

一句话记下来就走，不用先建项目。自动存进「收件箱」项目，第一行当标题。

### 6.4 版本与回滚

编辑器工具栏「版本」。

- 每次保存自动快照（每篇保留 50 份）
- 左侧列快照（时间 + 字数），右侧是它和当前正文的行级 diff
- 只显示变更点前后 3 行，中间折叠
- 一键回滚，**回滚前的内文也会存成快照**，滚错了能再滚回来

### 6.5 导入稿件

首页「导入稿件」，选 TXT 或 MD（可多选），**一个文件导入成一本新书**。

按章节标题自动拆分：

```
第一章 柴房          认
第3章 高潮           认
Chapter 12 The End   认
# 前言               认（Markdown 标题）
```

分章保守：只认整行、不超过 40 字、长得像标题的行。宁可少切一章，也不把正文中间一句话切成标题。

自动处理 GBK 编码和 BOM（老稿件很多不是 UTF-8）。

### 6.6 导出

左栏底部「导出」，选格式后系统对话框选位置。

| 格式 | 特点 |
|---|---|
| TXT | 一行一段，去 Markdown 标记，带 BOM（记事本不乱码） |
| 按章 MD | 一章一文件，细纲/人设/账本/伏笔/基线一起带走，换机器能接着写 |
| DOCX | 宋体 12pt、首行缩进两字符、每章分页、A4 |
| EPUB | EPUB 3 + NCX 双目录，mimetype 按规范放包首且不压缩 |

### 6.7 画板

**任何项目都能用。** 小说里叫「剧情编排」，其他叫「画板」。

| 项目类型 | 节点类型 |
|---|---|
| 小说 | 铺垫 / 转折 / 高潮 / 伏笔 / 悬念 |
| 文档、笔记 | 想法 / 待办 / 问题 / 资料 / 结论 |

交互和 AI 诊断同 5.11，只是分析维度换成通用项：孤立节点、缺少支撑、堆叠、断链、分支过多。

## 7. AI

### 7.1 接入

设置 → 模型，五个服务商：

| 服务商 | 说明 |
|---|---|
| DeepSeek | 默认，便宜、中文好 |
| OpenAI | GPT 系列 |
| Anthropic | Claude 系列 |
| Ollama | 本机跑，完全离线 |
| 自定义 | 任何 OpenAI 兼容接口 |

Key 用系统加密存储（Windows DPAPI），存在 `文档/墨匠/证书.bin`，**不在设置文件里，也不进 git**。

### 7.2 对话

右栏「AI 对话」。

- 流式输出，可中途停止
- 可选「带当前章节正文」一起发
- 发之前估算花费，超预算先问

### 7.3 把生成的段落用到正文

AI 回复超过 80 字时，下面会出现两个按钮：

- **用到正文**：打开分段选择面板
- **复制**：复制全文

分段面板里，回复按段落拆开（有空行按空行切，一行一段按换行切），每段显示字数和内容，默认全选。取消勾选不需要的段落，点「插入到本章末尾」，选中的段落会按顺序拼好追加到当前文档，并立即保存。

- 没打开文档时会提示先选一篇
- 插入后自动切回正文视图
- 不需要的段落直接取消勾选，不用先复制再删

### 7.4 写作指令

设置 → AI 指令，写一段话，比如：

```
- 保持第三人称限知视角，不写主角看不见的东西
- 少用形容词堆砌，多用动作和对话推进
- 对话要短，每个人说话方式要有区别
```

这段会拼在系统提示末尾，每轮请求都带上：

```
[内置硬规则 5 条]
【作者指定的写作指令，优先级高于上面的通用风格要求，必须逐条遵守】
[你的指令]
```

内置规则不可改：不替作者决定剧情、按章纲写、不整段复述正文。

### 7.5 花费

顶栏实时显示本月花费。调用前估算，超过单章或月度上限会拦下来问。

| `Ctrl+Shift+N` | 快速记录 |
| `Ctrl+Z` / `Ctrl+Y` | 编辑器内撤销 / 重做 |
| `Ctrl+B` / `Ctrl+I` | 加粗 / 斜体（编辑器内） |

## 11. 已知限制

| 限制 | 说明 |
|---|---|
| 榜单抓取不稳定 | 起点反爬、七猫连不上、番茄字体混淆。日常靠手动粘贴 |
| 台词提取是启发式 | 按名字附近 40 字取引号内容，多人对话场景会串，只作参考 |
| 画板与账本未联动 | 节点还不能同步伏笔状态、不能双击跳正文 |
| exe 图标是默认的 | 写 exe 元数据需要签名工具，普通权限解压失败；窗口和任务栏图标正常 |
| 无代码签名 | 首次运行会被 SmartScreen 拦，点"更多信息 → 仍要运行" |
| 无自动更新 | 需要 GitHub Releases + electron-updater，未接 |
| 体检仅中文 | 词表和切句都是针对中文小说调的 |
